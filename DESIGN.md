# Design Philosophy

## Overall Feel

- Premium
- Confident
- Modern
- Fast
- Minimal
- Elegant

## Inspiration

- Stripe
- Linear
- Apple
- Vercel
- Framer
- Notion

## Typography

Large headings.
Generous spacing.
Excellent readability.

## Motion

Subtle.
Smooth.
Purposeful.

Never distracting.

## Components

Rounded corners.
Soft shadows.
High contrast.

## Animations

Fade
Slide
Scale

Duration:
150–350ms

Ease:
ease-out

## Colors

Mostly neutral.

One accent color.

Avoid rainbow gradients.

## White Space

More whitespace than feels necessary.

Never cram content together.

## Code Quality

Animations should be reusable.

Components should be composable.

Avoid duplicate styling.

Accessibility is mandatory.
